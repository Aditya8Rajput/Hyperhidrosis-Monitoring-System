# Week_03 — System Design — Use Case Diagram & Operational Workflow

**Project:** HyperTrack — Hyperhidrosis Monitoring and Management System  
**Team Member:** Prabhkirat Kaur  
**Week:** 17-Aug-2026 to 23-Aug-2026

## Work Completed

- Created the formal Use Case Diagram illustrating primary patient interactions (log episode, view analytics, export report, track treatment).
- Developed detailed Use Case specifications documenting preconditions, main success flows, and exception scenarios.
- Designed the operational Activity Diagram mapping the decision logic for input validation, error handling, and report generation.
- Formulated the structured episode data schema defining HDSS severity, duration bounds, stress scale, and anatomical locations.
- Prepared high-resolution vector and raster diagram assets for the project documentation.

## Team Collaboration

The team reviewed design diagrams together, validated data flow consistency between Use Cases and DFDs, and aligned on module responsibilities.
