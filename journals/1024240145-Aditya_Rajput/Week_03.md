# Week_03 — System Design — Use Case, DFDs & Relational Schema

**Project:** HyperTrack — Hyperhidrosis Monitoring and Management System  
**Team Member:** Aditya Rajput  
**Week:** 17-Aug-2026 to 23-Aug-2026

## Work Completed

- Designed the Data Flow Diagrams (DFD Level 0 Context Diagram and Level 1 Detailed Decomposition).
- Designed the Entity-Relationship (ER) diagram specifying Users, Episodes, Triggers, and Treatments tables with foreign key constraints.
- Defined the normalized relational database schema in SQL with B-Tree indices on temporal fields `(user_id, timestamp)`.
- Implemented database constraint rules enforcing HDSS severity boundaries (1–4) and continuous duration limits.
- Documented system interfaces and data contracts for downstream analytics modules.

## Team Collaboration

The team reviewed the system design diagrams together, ensured naming consistency across all design artifacts, and finalized the database schema.
